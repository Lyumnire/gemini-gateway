🔄 Cookie Sync Bookmarklet

比扩展更可靠的 cookie 同步方式。不依赖 Service Worker。

步骤 1：添加书签

把下面的按钮拖到浏览器书签栏：

🔄 Sync Cookie

或者右键 → 添加到书签

步骤 2：使用

在 gemini.google.com 页面点击书签栏的 🔄 Sync Cookie 即可推送 cookie。

建议每次使用网关前点击一次，或在网关报错时点击。

原理

书签脚本直接从当前页面读取 cookie（HttpOnly 的 cookie 无法读取，需要用扩展或手动方式）。

⚠️ 注意：由于 __Secure-1PSID 和 __Secure-1PSIDTS 是 HttpOnly cookie，JavaScript 无法直接读取。此方案需要配合扩展使用，或手动在 Console 中运行以下命令获取 cookie：

// 在 gemini.google.com 的 Console 中运行：
chrome.cookies.get({url:'https://gemini.google.com', name:'__Secure-1PSID'}, psid => {
  chrome.cookies.get({url:'https://gemini.google.com', name:'__Secure-1PSIDTS'}, psidts => {
    fetch('http://127.0.0.1:8799/cookies', {
      method: 'POST',
      headers: {'Content-Type':'application/json', 'X-Token':'__TOKEN__'},
      body: JSON.stringify({cookies:{'__Secure-1PSID':psid.value,'__Secure-1PSIDTS':psidts.value}, reason:'manual'})
    }).then(r=>r.json()).then(d=>console.log('Result:', d))
  })
})
